Standard snippet rules decorative images
  • All snippets use: role="presentation", alt="", and include explicit width/height, with no trailing <br />.
  • Base URL: https://shared-files.online.umich.edu/michigan-online/
  • Course Images: https://shared-files.online.umich.edu/michigan-online/course-images/current/
  • Icons: https://shared-files.online.umich.edu/michigan-online/icons/current/

Snippet checklist: Use role="presentation" and alt="" for decorative assets, include explicit width and height, use the correct base URL for the category, and avoid trailing <br /> tags.

Accessibility note: These assets are treated as decorative. If an image conveys meaning, remove role="presentation" and replace alt="" with meaningful alt text.
